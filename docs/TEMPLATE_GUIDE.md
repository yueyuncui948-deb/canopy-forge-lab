# 母版使用方式

目前版本：研究流程母版 v0.1。文件制度已建立；尚未跑完整個遊戲開發與驗收循環，不能稱為已驗證的 v1.0。

## 複用到其他遊戲

1. 沿用 AGENTS 的通用規則、WORKFLOW、研究模板與文件檢查。
2. 修改 README、MASTER_PLAN、AGENTS 的專案目標、技術堆疊、預算與驗收標準。
3. 為新專案建立自己的 PROGRESS、DECISIONS 與 ASSETS；本專案歷史仍保留在原儲存庫，不在原庫刪除研究紀錄。
4. 新庫若保留舊任務作範例，需移至明確的範例目錄並標示來源版本，避免將舊測試當成新成果；正式任務重新編號。
5. 依新技術堆疊實測安裝、啟動與 CI，不直接宣稱沿用即通過。

## 母版升級

v1.0 必須至少完成一項遊戲任務的事前計畫、實作、測試、修正、審查及 Git 交付閉環，並驗證文件足以重建過程。未發生的失敗不得為展示流程而捏造。
保留歷史 commits；使用新版本紀錄補充制度改善。發布、付費服務或變更儲存庫可見性仍需明確授權。

目前母版附帶的 Sophia 人物是 CC BY-NC-SA 4.0 研究資產；通用流程與美術資產分開沿用。複用時保留來源與授權，不將範例人物的使用範圍誤認為程式流程的限制。
