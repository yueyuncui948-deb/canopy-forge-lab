# task-004：可選人物與近距離展示

## 目標
讓使用者在同一小型場景比較不同人物，改善只有 Sophia 可看的限制。新增 Babylon.js Assets 的 HVGirl，以較修長的人體比例比較既有 Q 版；不是換色複製。不擴張場景。

## 方案與理由
採具公開來源與授權的既有骨架模型，建立角色清單與骨架設定。保留 Sophia 作比較；先交付兩種實際不同的人物，不用低品質候選灌數量。HVGirl 原始只有 Idle／Walking／WalkingBack／Samba；快跑先以步行加速、空中與攻擊採程序姿態，介面與報告明示限制。這不等於最終寫實 ARPG 人物驗收。

加入人物展示模式，暫停遊戲戰鬥，以待機／步行／快步／跳躍／揮劍檢視骨架。支援全身／近看與現有滾輪環視。切換保留位置，載入失敗保留原角色，處理快速切換及資源釋放。

## 驗收
- 兩個不同 GLB 可由中文介面選取，顯示名稱、風格、動作限制及來源。
- 真實 WebGL 中逐一載入、近看、活動骨架與手骨掛劍；保存截圖。
- 展示暫停敵人與遊戲輸入；退出恢復，UI 操作不誤觸攻擊。
- 反覆切換、載入失敗有回歸，型別／單元／建置／既有遊戲回歸通過。
- 新資產保留固定來源版本、授權、SHA-256；XAMPP 子路徑可載入。

## 視覺篩選後調整（2026-10-22）
HVGirl 實際近看只有 1,872 三角形，面部與身體切面明顯，拒絕作為質感提升，改用 Microsoft Rocketbox Female_Adult_01／Male_Adult_01，保留 Sophia，共三個不同角色。Rocketbox README 明確說明人物庫已於 2020 年改為 MIT；下載固定版本來源，Blender 轉換 FBX、重建貼圖材質、世界空間骨架轉移並烘焙原庫 Idle／Walk／Run，移除水平 root motion。保留轉換腳本與原始檔案雜湊，可重建 GLB。跳躍／攻擊仍為程序姿態，現代服裝不是最終 ARPG 裝備。
