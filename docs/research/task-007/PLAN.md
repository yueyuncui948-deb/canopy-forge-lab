# task-007 計畫：Mixamo 動作庫導入

## 任務資料

2026-10-22（Asia/Taipei），main 起始 8ec8338。使用者要求：從 Mixamo 找齊移動（走、跑、蹲走）、跳躍、攻擊（單擊、二連擊、三連擊、施法）、其他（受傷、被攻擊、倒地）動作，歸納整理；Git 需開區記錄並整理名稱（下載檔名如「Sword And Shield Slash (2).fbx」）。

## 目標與範圍

1. 以 Mixamo API 搜尋並經使用者同意由瀏覽器下載 17 段；以影格數與根位移辨識檔案，統一命名 `mx-<類別>-<動作>.fbx`，登記素材總表（原檔不進 Git）。
2. 分析各攻擊段數，決定單擊／二連擊／三連擊對應。
3. 重新綁定到 A1–A4、B1、B2，取代 Xbot 測試動畫與程序揮劍；遊戲加入操作與受擊、倒地、重生。

## 方案比較與選擇理由

統一用 Mixamo「Sword And Shield」系列（單手持劍、風格一致）；缺的蹲走、向前施法以其他系列補。原始 FBX 依 Mixamo 條款不單獨散布。

## 驗收標準與操作順序

步態方向、滑步、擊中時刻落在揮劍高峰（單元）；A3 下劈鎖定移動、蹲走速度、施法（瀏覽器 smoke）；既有回歸全部通過。
