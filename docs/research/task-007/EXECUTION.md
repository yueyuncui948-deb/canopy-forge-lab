# task-007 執行紀錄

1. 使用者於自己的瀏覽器登入 Mixamo；以頁面內 API（/api/v1/products）搜尋動作包與單一動作，取得描述、影格、是否支援原地。使用者同意後以 /api/v1/animations/export 逐一匯出（X Bot、FBX、Without Skin、30 fps、無精簡；移動類原地），共 17 段。工具單次呼叫上限 45 秒，迴圈在頁面內持續執行後再讀結果。
2. 使用者上傳的檔名依 Mixamo 名稱並由瀏覽器加 (1)(2)；以 three.js FBXLoader 解析影格數與骨盆位移逐一對應，改名為 mx-<類別>-<動作>.fbx 存於 asset-library/raw/MX/，素材總表 MX01–MX17 記錄原始檔名、整理後檔名、影格、原地、根位移、SHA-256。MX14 實際 30 影格與 Mixamo 列表的 23 不同，已註記。
3. 段數分析（scripts/assets/analyze_swings.mjs，右手相對骨盆速度峰值）：下劈 1、橫斬 2（交叉兩刀）、雙手連擊 3、單手連擊與劍盾連擊各 4。首次以世界座標計算，連擊根位移造成 74 m/s 異常峰值而算出 0 段，改為相對骨盆。
4. 直接把 FBX 動畫套在 X Bot GLB 上呈現倒立：兩者父節點座標系不同，改走重新綁定流程。新增 scripts/assets/retarget_mixamo.mjs（來源改為 FBX、多段同時處理）。FBX rest 為 T-pose、Y 上、正面 +Z、公分。
5. 六位人物重新綁定 17 段並壓縮（每位增加約 0.3 MB）。量測新走、跑、蹲走著地腳速度：劍盾走路為戒備側步，兩腳速度不同，以領先腳換算倍率；新移動速度 Walk 2.2、Run 5.2、蹲走 1.5。
6. 遊戲：catalog.ts 新增 Moves（clip 名與擊中時刻）；hero.ts 動作層（一次性動作、預覽、蹲走、真實起跳）；main.ts 操作 J／K／L／Q／C、動作期間鎖定移動、依擊中時刻判定傷害、怪物攻擊觸發受擊、HP 歸零倒地並於數秒後重生；圖庫展示加入蹲走、二連擊、三連擊、施法、受擊、倒地（僅 Mixamo 角色顯示）。
7. 測試：姿勢還原器測試在新 Idle 上失敗——Mixer 每次 setTime 產生約 0.0002 rad 浮點差，原測試以「完全相同」為前提過於嚴格；改以動畫未寫入的骨頭驗證累加風險（更貼近實際風險）。素材總表雜湊測試在模型更新後如預期失敗，更新紀錄後通過。
