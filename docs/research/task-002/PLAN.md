# task-002：可建置的遊戲與重生回歸驗證

日期：2026-10-22（Asia/Taipei）。起始版本：83d0606。直接在 main 工作。

## 目標與範圍

準備可重現依賴、實際重現既有建置失敗、修正怪物死亡／重生，驗證遊戲啟動、走跑跳與攻擊，建立建置與瀏覽器回歸流程。維持原有小場景與占位人物，不導入美術資產，不擴張場景。

## 方案與理由

只改錯字最快，但重生資料仍藏在無型別 userData，難測死後攻擊與重複排程。選擇抽取小型、具型別的怪物生命週期模組，搭配 Node 內建測試；保留大部分場景程式，完整系統拆分另做。
瀏覽器使用 Playwright，讀取明確啟用的唯讀狀態快照並實際發送鍵盤／滑鼠事件，不提供傳送、扣血等作弊測試入口。測試以狀態變化與截圖為證據，不宣稱最終視覺或 GPU 效能達標。

## 操作順序

記錄計畫 → 安裝依賴與鎖檔 → 保存原始建置失敗 → 修正與測試 → 啟動真實瀏覽器驗證 → 自我審查 → 保存研究紀錄與雲端啟動設定 → main 提交推送。

## 驗收

- npm ci 可重現安裝；型別與正式建置通過。
- 單元測試涵蓋扣血、死亡、死後攻擊、重生時間與重複更新。
- 真實瀏覽器可渲染、走跑跳、攻擊扣血，怪物死後三秒遊戲時間重生且沒有 pageerror。
- 保存截圖、測試數量、實際命令與退出碼；新 CI 執行同樣指令，遠端結果另核對。
- 更新 README 與進度，列出方向、碰撞、怪物攻擊等仍待處理項目。
