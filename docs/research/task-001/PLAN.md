## 目標與範圍

建立繁體中文、自主執行且可追溯的研究制度。分離通用流程與本遊戲規格，維持約 30–40 公尺的小型場景、五棵主樹、一位精緻主角與一隻怪物。
本任務交付文件、五份研究模板、PR 模板及文件 CI；遊戲建置 CI 留待依賴與既有程式問題解決後啟用。保留遊戲原始碼與依賴宣告。

## 方案比較與選擇

1. 所有規則寫進 AGENTS.md：入口直接，但難以複用且容易混入遊戲細節。
2. AGENTS.md 作入口，通用流程、專案規格、研究證據分開：可複用且責任清楚；採用此方案。
3. 同時開始遊戲修復：驗證更完整，但會混合母版制度與遊戲變更；另立 task-002。

## 預定操作

建立任務分支 → 提交本計畫 → 更新文件與模板 → 增加文件檢查與 CI → 執行檢查及自我審查 → 保存結果 → 提交 → 嘗試推送與建立 PR。
GitHub API 或寫入權限不足時，保留本機 commits 與精確阻塞，不繞過權限。僅符合既定檢查與分支保護時合併；遠端 CI 未執行不能宣稱通過。
