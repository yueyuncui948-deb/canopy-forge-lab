# task-009 計畫：握劍方向校正與攻擊段數更正

## 任務資料

2026-10-23（Asia/Taipei），main 起始 9a05d38。使用者懷疑「拿劍方向不對導致揮刀怪」，要求仔細校正。

## 目標與範圍

1. 握法改為依手部解剖：刀身沿虎口（小指根→食指根）伸出、刃口朝指關節。
2. 以刀尖速度重新判定各攻擊的擊中時刻與段數，修正二連擊／三連擊對應。

## 方案比較與選擇理由

逐骨架用手指骨推算：A3 無手指骨、各骨架命名不同。改在 X Bot（Mixamo 原骨架，手指完整）上算握法，再用重新綁定的旋轉關係換算到目標手骨，烘焙成 SwordGrip 節點；與 Mixamo 動作設計時的持劍方向一致，且所有骨架共用同一定義。

## 驗收標準與操作順序

待機刀尖朝上；擊中瞬間刀尖速度／手速度 > 1.3；擊中時刻落在刀尖速度峰值；全部回歸通過。
