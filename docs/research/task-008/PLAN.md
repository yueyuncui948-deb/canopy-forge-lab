# task-008 計畫：動作手感改善

## 任務資料

2026-10-22／23（Asia/Taipei），main 起始 d026180。使用者要求在其本機（localhost:5173）實際觀察後思考並優化動作。

## 目標與範圍

依使用者本機畫面逐格擷取觀察：攻擊朝向舊面向、揮空；連擊原地播放造成腳步滑動；連段需分鍵操作；收招鎖定過久。改善：自動面向、根位移、J 連段、收招取消。

## 方案比較與選擇理由

根位移以獨立 RootMotion 節點保存（不改骨盆原地），執行時只在一次性動作期間套用變化量，淡出時不套，避免往回拉。連段以既有 clip 區段組合（下劈 → 交叉斬 → 雙手連擊最後一刀），不另外剪檔。

## 驗收標準與操作順序

連段擊中時刻落在揮劍高峰；倒地停在倒下姿勢；瀏覽器：擊中前方向鍵不改面向、擊中後按方向在完整動作前取消；全部回歸通過。
