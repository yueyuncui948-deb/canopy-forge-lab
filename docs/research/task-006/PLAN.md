# task-006 計畫：測試瘦身與補齊、揮劍修正

## 任務資料

2026-10-22（Asia/Taipei），main 起始 0d727cd。使用者要求：評估無效與拖累時間的測試並過濾，補齊缺少的測試；並回報新角色揮刀「非常詭異」，要求檢查。

## 目標與範圍

1. 以實測耗時評估瀏覽器測試，移除重複、合併同路徑、去掉測檔案而非測遊戲的斷言。
2. 能在 Node 驗證的人物資產性質改為單元測試，涵蓋全部角色。
3. 分層：@smoke 與完整回歸，並寫入 AGENTS／README。
4. 揮劍：查明新骨架上詭異的原因並修正，加上全部角色的方向測試。

## 方案比較與選擇理由

揮劍正解為真實攻擊動畫（需使用者下載 Mixamo）；本任務先把程序姿態改為與骨架無關的角色座標，作為暫代。

## 驗收標準與操作順序

單元測試能抓到刻意破壞（模型轉 180°、走路倒放）；全部角色揮劍方向一致；完整瀏覽器回歸於無並行負載下通過並記錄耗時。
