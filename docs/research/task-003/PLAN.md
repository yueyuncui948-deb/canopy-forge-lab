# task-003：優先替換積木占位主角

日期：2026-10-22（Asia/Taipei）。起始版本：512eb90。直接 main。

## 使用者需求與調整

使用者本機展示後指出人物缺乏質感、像積木，明確要求先處理角色。優先順序因此提前到人物視覺；不等待原定完整 P2。維持小場景，保留已有走跑跳／攻擊／重生回歸。

## 目標與方案

採用授權清楚、可隨本專案散布的連續表面骨架人物，提供人體比例、臉部／衣物細節、材質與動畫。不得只增加幾何塊數或用靜態圖片偽裝 3D。
先比較可用的公開人物資產與授權；若選用模型需記錄來源、授權原文、雜湊及修改。透過 GLTFLoader、AnimationMixer 與手骨武器連接整合現有操作。必要時調整鏡頭距離與人物補光，讓使用者能看清成果，但不擴大場景。

## 驗收

- 主角為真實 skinned mesh，有可辨認頭臉、身體與服裝，移除原本膠囊／球體主角。
- 正常遊戲視角及近看模式都能看清人物，保存實際瀏覽器截圖。
- 走跑跳與攻擊有可觀察骨架姿態，武器隨手部移動。
- 資產在專案內可離線載入，兼容 XAMPP 子路徑，不依賴執行時外部 CDN。
- 型別、建置、既有測試與新增人物載入／動畫測試通過；保留失敗與視覺限制。
- 依證據說明改善，不把第一版人物整合宣稱為最終寫實美術驗收。

## 尚待確認

資產選型依可取得性、授權及實際視覺比較決定。若沒有可合法取得的合格人物，不回退積木冒充完成。
